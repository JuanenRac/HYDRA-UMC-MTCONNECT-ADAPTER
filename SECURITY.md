## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In an industrial monitoring adapter, a security flaw can lead to information leakage or spoofing of machine health data. If you discover a vulnerability affecting the **HTTP server exposure**, **XML injection**, or **state masking**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows unauthorized monitoring of robotic activity, providing false health data to ERP systems, or crashing the legacy bridge.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
